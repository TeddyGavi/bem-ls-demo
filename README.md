# bem-ls Demo

Try **[bem-ls](https://github.com/TeddyGavi/bem-ls)**, a BEM language server, in a ready-to-use VS Code environment powered by GitHub Codespaces.

This repository provides a convenient way to explore `bem-ls` without setting up a local development environment.

## Try the Demo

1. Open this repository on GitHub: [TeddyGavi/bem-ls-demo](https://github.com/TeddyGavi/bem-ls-demo).
2. Click **Code → Codespaces**.
3. Select **Create codespace on main**.
4. Wait for the development environment to finish starting.
5. Open one of the example files and try the BEM language features provided by `bem-ls`.

You need a GitHub account with access to GitHub Codespaces. Codespaces usage may be subject to account quotas and billing.

## About bem-ls

[`bem-ls`](https://github.com/TeddyGavi/bem-ls) is a language server for working with BEM (Block, Element, Modifier) naming conventions in stylesheets and related code.

The language server is designed to bring BEM-aware tooling into compatible editors through the Language Server Protocol (LSP).

See the main repository for supported features, configuration, and development details.

## What's Included?

- A GitHub Codespaces development environment.
- Example files for trying out BEM-related language features.
- A preconfigured environment intended to reduce setup time.

## Local Development

You can also clone this repository and open it in a compatible version of Visual Studio Code.

```bash
git clone https://github.com/TeddyGavi/bem-ls-demo.git
cd bem-ls-demo
```

If you use VS Code, reopen the folder in a development container when prompted, or use the **Dev Containers: Reopen in Container** command.
